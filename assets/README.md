# Copmito asset pack

This folder contains lightweight placeholder pixel-style SVG assets for the starter Godot RPG project.

Files included:
- grass_tile.svg
- stone_wall.svg
- player.svg
- enemy.svg
- boss.svg
- npc.svg
- coin.svg

These are starter art assets intended for prototypes. Replace them later with full sprite sheets or tilesets as the game grows.
